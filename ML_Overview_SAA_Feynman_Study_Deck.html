Готові AI-сервіси

Головна ідея (аналогія)

Готові спеціалісти 'напрокат' замість навчання власного експерта

  • Уяви, що замість роками навчати власного експерта розпізнавати обличчя на фото — можна просто 'найняти' готового спеціаліста на годину через API-виклик.
  • AWS пропонує НАБІР готових, вже натренованих AI-сервісів для типових задач (розпізнавання зображень, перетворення голосу в текст тощо) — не треба збирати датасет чи тренувати модель самому.
  • На SAA-C03 достатньо знати НАЗВУ сервісу для кожної задачі — а не як він працює 'під капотом'.
1. Пре-треновані AI-сервіси

Каталог сервісів за задачею

Мастхев напам'ять — 'задача → сервіс'

  • Rekognitionаналіз зображень і відео — розпізнавання об'єктів, облич, NSFW-контенту (модерація).
  • Transcribeмова → текст (speech-to-text) — субтитри, транскрипція дзвінків.
  • Pollyтекст → мова (text-to-speech) — озвучка, голосові інтерфейси.
  • Translateпереклад тексту між мовами.
  • Comprehendаналіз тексту природною мовою (NLP) — тональність (sentiment), ключові фрази, сутності.
  • Comprehend Medicalте саме, але спеціалізоване на медичних текстах (діагнози, ліки).
  • Lexрушій для чат-ботів (той самий движок, що й Alexa) — розуміння намірів користувача.
  • Textractвитягує ТЕКСТ і СТРУКТУРУ (таблиці, форми) зі сканованих документів/зображень — 'розумний OCR'.
ЗАПАМ'ЯТАЙШвидкий трюк: назва сервісу часто підказує задачу — 'Transcribe' (транскрибувати = записати мову текстом), 'Translate' (перекласти), 'Textract' (text + extract).

Розділ 2

SageMaker та спеціалізовані ML-сервіси

Коли готового API замало

Amazon SageMaker

Повна платформа для побудови ВЛАСНИХ ML-моделей

  • На відміну від готових API (Rekognition, Comprehend тощо), SageMaker — це платформа, де ТИ (чи твоя data science команда) будуєш, тренуєш і розгортаєш ВЛАСНУ ML-модель під специфічну задачу бізнесу.
  • Покриває весь цикл: підготовка даних (SageMaker Ground Truth для розмітки), тренування моделі, розгортання (endpoint) для отримання прогнозів у реальному часі.
  • На SAA-рівні досить розуміти: SageMaker = 'коли готового пре-тренованого сервісу недостатньо, і потрібна КАСТОМНА модель'.
ЗАПАМ'ЯТАЙ'Потрібна модель, натренована на НАШИХ власних унікальних даних' → SageMaker. 'Потрібно просто розпізнати текст/обличчя стандартним способом' → готовий API-сервіс (Rekognition/Textract тощо).

Підсумок: Machine Learning одним поглядом

  • Пре-треновані API (не треба тренувати самому): Rekognition (зображення), Transcribe (голос→текст), Polly (текст→голос), Translate, Comprehend (NLP), Textract (OCR+структура), Lex (чат-боти)
  • SageMaker: коли потрібна ВЛАСНА кастомна модель на власних даних, а не готовий API
  • Kendra (пошук), Personalize (рекомендації), Forecast (прогнози), Fraud Detector (шахрайство) — вузькоспеціалізовані сервіси

На іспиті ML-питання зазвичай прості 'впізнай сервіс за задачею' — не переживай за глибокі ML-знання, зосередься на назвах і призначенні.
