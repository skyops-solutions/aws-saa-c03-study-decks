НОВИЙ СЕРВІС В SAA-C03

1. Amazon Bedrock — Серверлес генеративний ШІ

  • Повністю керований (Serverless) API для Foundation Models (FM): Доступ до найкращих моделей від провідних AI-компаній: Anthropic Claude, Meta Llama, Mistral AI, AI21 Labs, Stability AI та Amazon Titan без необхідності керувати жодними серверами чи GPU.
  • Приватність та безпека даних (Data Privacy): Ваші дані, передані через Bedrock, НЕ використовуються для донавчання базових моделей і залишаються ізольованими у вашому AWS акаунті (VPC PrivateLink, KMS encryption).
  • Customization (Fine-tuning): Можливість донавчати моделі на власних даних у приватному S3-бакеті без розкриття промптів.
EXAM TIP (SAA-C03)Якщо в питанні вимагається інтегрувати генеративний ШІ (LLM) без розгортання та адміністрування інфраструктури/GPU — правильною відповіддю ЗАВЖДИ є Amazon Bedrock, а не SageMaker!

2. Bedrock Knowledge Bases & RAG

  • Retrieval-Augmented Generation (RAG): Архітектурний патерн, де LLM шукає актуальну корпоративну інформацію у векторній базі даних (OpenSearch, Pinecone, Aurora PostgreSQL pgvector) перед генерацією відповіді.
  • Amazon Bedrock Knowledge Bases: Автоматично підключає ваші документи з Amazon S3, генерує ембедінги (Embeddings) через Amazon Titan Embeddings і зберігає їх у Vector DB для точного пошуку.
  • Amazon Bedrock Agents: Агенти можуть автоматично розбивати запит користувача на кроки, звертатися до внутрішніх систем через AWS Lambda та виконувати дії (наприклад, забронювати квиток чи оновити запис у БД).
EXAM TIPКоли потрібно, щоб модель відповідала строго на основі внутрішніх PDF/документів компанії в S3 — обирайте Bedrock Knowledge Bases (RAG).

3. Amazon Q та Amazon Kendra

  • Amazon Q Developer / Business: Генеративний AI-помічник корпоративного рівня. Підключається до Slack, Confluence, Jira, S3, Salesforce і відповідає на питання співробітників з урахуванням прав доступу (ACL).
  • Amazon Kendra — ML-пошуковик: Інтелектуальний семантичний сервіс корпоративного пошуку. Шукає сенс документів (NLP), а не просто точні збіги ключових слів.
  • Kendra vs OpenSearch: Kendra — готовий сервіс для бізнес-документів з коробки. OpenSearch — гнучкий двигун для логів, аналітики та кастомного повнотекстового/векторного пошуку.
EXAM TIPЯкщо в компанії є тисячі інструкцій у Sharepoint/S3/Salesforce і потрібен готовий семантичний пошук без навчання моделей — обирайте Amazon Kendra.

4. Amazon SageMaker — Повний цикл ML

  • Коли використовувати SageMaker замість Bedrock: SageMaker використовується, коли датасаєнтисти навчають власні ML-моделі з нуля (Custom Algorithms: XGBoost, TensorFlow, PyTorch), управляють навчальними кластерами та розгортають інференс.
  • SageMaker Endpoints: Real-time (мілісекундні затримки), Serverless (для нерегулярного навантаження), Asynchronous (обробка великих файлів до 15 хв), Batch Transform (масова обробка всіх даних одночасно).
  • SageMaker Canvas: No-Code візуальний інтерфейс для бізнес-аналітиків, який будує прогнозні моделі без написання жодного рядка коду.
EXAM TIPДля нерегулярного трафіку з періодами простою обирайте SageMaker Serverless Inference, щоб автоматично масштабуватися до 0 і не платити за простій EC2 інстансів.
